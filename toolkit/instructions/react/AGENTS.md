# Adaptador React

Identifique framework, versão, TS/JS, gerenciador, rotas, estilos e testes nos arquivos reais. Preserve estrutura e convenções locais; este adaptador orquestra skills e não as reescreve.

- Carregue `react-frontend` para trabalho React.
- Carregue `impeccable` em trabalho de interface, design, UX ou refinamento visual.
- Para feature ponta a ponta, testes e revisão, carregue `criar-feature`, `criar-testes` e `code-review` conforme escopo.
- Se a tarefa envolver ameaças ou dados pessoais, selecione `attack-defense`, `data-security` e/ou `lgpd`.

Leia a skill principal após selecioná-la e só abra referências/recursos que ela solicitar. Não imponha Next, Vite, router, UI kit, estado global ou nova dependência.
