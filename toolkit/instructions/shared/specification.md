# Specification-Driven Development

Siga o fluxo: elaborar especificação → localizar ambiguidades → validar restrições e segurança → planejar → implementar em partes pequenas → testar → verificar cada critério de aceitação → registrar limitações e resultados.

Cada critério deve descrever observação verificável. Use Given/When/Then quando esclarecer comportamento. Não trate ausência de informação como autorização; registre decisões menores conservadoras.
