# Adaptador Flutter/Dart

Este arquivo seleciona conhecimento especializado; não replica a skill. Primeiro detecte SDK, pacote e arquitetura pelo código e instruções do projeto. Preserve os padrões encontrados.

- Sempre carregue `flutter-development` para implementação/manutenção Flutter.
- Carregue `flutter-architecture` somente se Modular/MobX estiver presente ou solicitado. Não converta Provider nem outra arquitetura incidentalmente.
- Para bootstrap de app, carregue `criar-projeto-flutter`.
- Para feature ponta a ponta, carregue `criar-feature`; para testes, `criar-testes`; para revisão, `code-review`.
- Se Firebase estiver configurado, carregue `firebase-development` e as skills de segurança/privacidade pertinentes.
- Em app PKT Personal identificado, priorize `pkt-personal-architecture`; para feature use `pkt-personal-feature`, para review `pkt-personal-code-review`. Confirme a diferença Provider/Firebase e módulos migrados no repositório.

O carregador lê primeiro o frontmatter e a descrição; só depois lê o `SKILL.md` selecionado e, quando necessário, a referência/script que ele indica. Não carregue todas as skills por padrão.
