# Adaptador Node.js

Detecte runtime, JS/TS, módulos, framework, banco, scripts e testes pelo projeto. Preserve seus contratos e arquitetura; este adaptador direciona para conhecimento especializado.

- Carregue `node-architecture` para backend Node.
- Para feature ponta a ponta, testes ou review, carregue `criar-feature`, `criar-testes` e `code-review` conforme tarefa.
- Se envolver ameaças/API, selecione `attack-defense`; para dados pessoais, `data-security`/`lgpd`; para desempenho/capacidade, `escalabilidade`.
- Para Firebase, carregue `firebase-development` e confirme se o acesso é client SDK ou Admin SDK.
- Em projeto PKT identificado, use as skills PKT correspondentes sem generalizá-las.

Leia a skill principal da seleção e carregue referências somente quando necessárias. Não presuma Express, NestJS, Fastify, banco de dados ou migração.
