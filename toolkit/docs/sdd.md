# Specification-Driven Development

Copie `templates/specifications/feature.md`. Preencha problema, objetivo, escopo, requisitos, regras, arquitetura, segurança, cenários, testes e Definition of Done. Escreva critérios observáveis, usando Given/When/Then se útil. Rode `python toolkit/scripts/ai_toolkit.py validate-spec caminho/feature.md`. O validador confirma presença de seções, não qualidade semântica; a revisão humana ainda verifica ambiguidades e testabilidade. Planeje antes de implementar e valide cada critério ao final.
