# Início rápido

Tenha Python 3.10+, copie `toolkit/` ao projeto e mescle as regras compartilhadas com as instruções locais. Execute `python toolkit/scripts/ai_toolkit.py inspect .` para ver o que foi detectado. Crie uma especificação copiando `templates/specifications/feature.md`, valide com `validate-spec`, depois rode `validate` e leia JSON/Markdown gerados em `.ai-toolkit/`. Ajuste manualmente scripts não reconhecidos; nenhuma API key é necessária.
