# Evals do toolkit

Os casos em `cases/` são fixtures determinísticas e offline. Execute `python toolkit/evals/run_evals.py` e `python -m unittest discover -s toolkit/tests`. Cobrem fluxo de trabalho, detecção de stack, especificação, padrões arquiteturais declarados, revisão, segurança, privacidade e rastreabilidade. Eles exercitam o toolkit, não provam confiabilidade geral de agentes. Evals com LLM são futuras, probabilísticas e exigirão provedor configurado, datasets versionados e revisão humana.
